
# Описание
**Виртуальная медкарта “MedSpase”**
В этом приложении будут храниться все медицинские данные о пользователе, его анализы, принимаемые препараты, пройденные обследования и те, которые в планах.
Профиль пользователя: фио, возраст, вес, рост, ИМТ, возможно что-то еще.Создание профилей для членов семьи

## Принимаемые препараты:
*	Их название, для чего применяются
*	Продолжительность применения, дни и время, когда нужно принимать препарат
*	Напоминание по времени о том, что нужно принять препарат
*	История приема препаратов
  
## Анализы:
*	История сдачи анализов
*	Результаты анализов
*	Показатели, на которые стоит обратить внимание
  
## Модуль «Визиты к врачам и прививки»:
*	Архив визитов к врачам: фио врачей, название поликлинник
*	Календарь врачей, которые планируется посетить
*	Ежегодный план посещения
  
## Показатели здоровья:
*	Дневник для регулярного ввода данных: давления, пульса, уровня сахара в крови или температуры
